# 1917 러시아를 구하라

중학교 2학년 세계사 수업용 웹게임. 교육 목표와 실제 역사 흐름의 기준은 `PRD.md`입니다.

## 현재 구현 범위

장면 1~9, 선택 결과, 2월·10월 혁명 이벤트, 역사 흐름 엔딩, 무채점 사고 질문과 다시 플레이를 구현했습니다. 선택지 수는 3·4·5·3·3·4·3·0·3개이며 Scene 8은 역사 설명 장면입니다. 일부 병사의 시위 합류와 임시 정부의 전쟁 지속에 연결된 역사 발견 배지 두 종류를 포함합니다. 장면 1~8에 생성한 역사 상황 일러스트를 적용했으며 장면 9는 첫 장면 그림을 재사용합니다. 그림은 실제 사진이나 사료가 아닌 학습용 재구성입니다. 전체 플레이 시간 20분 이내는 학생 시범 플레이로 검증해야 합니다.

## 개발

파일 하나로 확인하려면 `russia-1917-prototype.html`을 엽니다. 게임 코드와 스타일을 모두 포함합니다. 지정한 글꼴은 Google Fonts와 jsDelivr에서 불러오며, 연결이 불가능하면 기본 글꼴로 표시됩니다. `index.html`도 같은 단일 HTML로 생성되어 바로 열 수 있습니다. 소스 변경을 즉시 확인하는 개발 화면은 개발 서버의 `/dev.html`입니다. 소스를 수정한 뒤 `npm run build:standalone`으로 단일 HTML을 갱신합니다.

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 검증 환경은 Node.js 24입니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

콘텐츠는 `src/data/scenes.js`, 상태 전환과 게이지 계산은 `src/game/state.js`, 화면은 `src/main.jsx`, 반응형 스타일은 `src/styles.css`에 있습니다. 상단 게이지는 각 장면의 실제 역사 상황을 학습용으로 나타냅니다. 선택의 예상 영향은 결과창에 따로 표시하고 다음 장면에는 누적하지 않습니다. 수치는 역사적 측정값이 아닙니다.

## 확인할 점

- 결과를 읽은 뒤 계속 버튼으로만 진행하며 어떤 선택에도 게임오버가 없습니다.
- 장면 4의 선택 뒤 모든 경로가 2월 혁명·차르 퇴위·임시 정부를 거치고, 장면 7의 레닌·볼셰비키 등장 후 장면 8의 10월 혁명·소비에트 정부를 확인합니다.
- 장면 4의 일부 병사 합류와 장면 5의 전쟁 지속 선택에 역사 발견 배지가 등장합니다.
- 배지 수·등수·빈 수집 칸을 표시하지 않습니다.
- 1024×768, 1366×768, 태블릿 세로 화면에서 읽기와 터치를 확인합니다.
- 임시 배경은 CSS로 표시하며 외부 이미지·비밀키는 필요 없습니다. 제목은 주아, 본문은 고운돋움, 강조는 카페24 심플해를 사용합니다.

현재 빌드는 상대 경로 자산을 사용하여 정적 하위 경로에 배포할 수 있습니다. 실제 배포는 아직 하지 않았습니다.

상태 테스트는 가능한 선택 경로 19,440개에 대해 역사 사건 순서·8회 선택·배지·사고 질문 3개 응답의 무채점·재시작을 확인합니다.

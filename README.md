# 1917 러시아를 구하라

중학교 2학년 세계사 수업용 웹게임. 교육 목표와 실제 역사 흐름의 기준은 `PRD.md`입니다.

## 시제품 범위

시작 화면, 장면 1~3(선택지 3·4·5개), 장면 4의 2월 혁명 요약, 장면 5 임시 정부 선택과 역사 발견 배지 예시, 시제품 정리 화면을 구현했습니다. 장면 4의 선택과 장면 6~9·최종 엔딩·사고 질문은 아직 구현하지 않았습니다. 전체 플레이 시간 20분 이내는 학생 시범 플레이로 검증해야 합니다.

## 개발

파일 하나로 확인하려면 `russia-1917-prototype.html`을 엽니다. 게임 코드와 스타일을 모두 포함합니다. 지정한 글꼴은 Google Fonts와 jsDelivr에서 불러오며, 연결이 불가능하면 기본 글꼴로 표시됩니다. `index.html`도 같은 단일 HTML로 생성되어 바로 열 수 있습니다. 소스 변경을 즉시 확인하는 개발 화면은 개발 서버의 `/dev.html`입니다. 소스를 수정한 뒤 `npm run build:standalone`으로 단일 HTML을 갱신합니다.

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 검증 환경은 Node.js 24입니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

콘텐츠는 `src/data/scenes.js`, 상태 전환과 게이지 계산은 `src/game/state.js`, 화면은 `src/main.jsx`, 반응형 스타일은 `src/styles.css`에 있습니다. 게이지 수치는 초기 시제품용으로 조정 가능합니다. 변화는 역사적 측정값이 아닙니다.

## 확인할 점

- 결과를 읽은 뒤 계속 버튼으로만 진행하며 어떤 선택에도 게임오버가 없습니다.
- 장면 3 뒤 모든 선택 경로가 2월 혁명·황제 퇴위·임시 정부 요약을 거칩니다.
- 장면 5의 전쟁 지속 선택에만 교과서 184쪽에 근거한 배지 예시가 등장합니다.
- 배지 수·등수·빈 수집 칸을 표시하지 않습니다.
- 1024×768, 1366×768, 태블릿 세로 화면에서 읽기와 터치를 확인합니다.
- 임시 배경은 CSS로 표시하며 외부 이미지·비밀키는 필요 없습니다. 제목은 주아, 본문은 고운돋움, 강조는 카페24 심플해를 사용합니다.

현재 빌드는 상대 경로 자산을 사용하여 정적 하위 경로에 배포할 수 있습니다. 실제 배포는 아직 하지 않았습니다.
